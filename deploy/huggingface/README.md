# Amoxcalli · demostración

Plataforma para aprender náhuatl clásico con lecturas guiadas, análisis de palabras, un buscador de grafías (clásica, moderna y de cada variedad), diccionario con fuentes, dioses y calendario. Cada resultado indica de dónde viene; sin evidencia, la aplicación se abstiene.

Esta es una **demostración de solo lectura**: no guarda aportaciones ni grabaciones. Las ayudas de lectura y las entradas automáticas están pendientes de revisión lingüística.

Fuentes y licencias: corpus Axolotl (UNAM, distribución Elotl), Vocabulario de Molina vía GDN (UNAM), Wiktionary (CC BY-SA 4.0), Carochi (1645, dominio público) y catálogo Tlachia (UNAM; imágenes cargadas desde su sitio, con atribución). El detalle de cada ficha está en la aplicación.
