## Exceptions and next source pass

Missing cache and capped prefix pages appear in sources.json. A capped page does not establish source exhaustiveness. next-source-config.json groups up to eight prefix requests, drawn from frequent unmatched forms; prefixes are search partitions, not inferred roots. Unmatched tokens and exact/ambiguous form candidates appear in annotation-candidates.json; none is applied automatically. Concordances preserve evaluation reservations and empty meanings.

Review-groups.json allows one source/scope decision per group, with individual exceptions in items. Record accepted/rejected/deferred decisions in the separate editorial/pipeline-decisions.json. Acceptance needs matching fingerprint, reviewer, date, evidence and a scope-limited resolution. Assemble produces a validated append-only bundle; it does not import it or train the model.
