## Iterations

### 0 · Clone, test, demo — done 15 October 2026 (except item 4 above)
- Inputs are tracked; `reports/` keeps only current, regenerable reports plus provenance cited by distributed data ([reports/README.md](../reports/README.md)). `make reports` regenerates, `make check` validates.
- Hash gates cover only measured inputs. Presentation is verified by the DOM suite (`make test-ui`); a UI-only change no longer requires regenerating evidence.

### 1 · One search across spellings
- **1a done (15 Oct): term index and one search.** `terms.py` groups each word with all its attested spellings (colonial, SEP/INALI, inflected), passages by variety and pictographic references with their scope (dictionary glyphs; Tlachia elements and readings); homographs (*tlacualli* vs *cualli*, *cohua* vs *coatl*) and words that only contain the term (*mixcoatl*) are listed apart, never counted. One pipeline (normalize → loose key / root → order) serves Diccionario, Archivo, Preguntar and Consultar fichas; `/api/search`, `CorpusStore.search`, the browser-side dictionary filter and the "¿forma flexionada?" suggestion were removed. Guide: [ARCHITECTURE.md §7](ARCHITECTURE.md).
  - **Measure** ([reports/EVALUACION.md](../reports/EVALUACION.md#evaluación-de-grupos-de-término), formerly `TERMINOS_EVALUACION.md`, `evaluation/term-groups-v1.json`, 21 terms written before the index): test split (14 terms) — query → expected group 85.7% of 42 queries (81.0% on the first run, kept in `reports/term-groups-evaluation-first-test-run.json`; two generic fixes since: dictionary labels decide the language, roots under 3 symbols no longer pick a group), spelling coverage 95.5%, glyph coverage 100% (20/20 with scope), labeled precision 100% for spellings and glyphs. Dev: 96.7% of 30 queries, homographs kept out 9/9. Unchanged: Preguntar evaluation (entry@1 92.3% test, passage precision 94.4%), morphology evaluation, documentary lookup 119/123 (its ranker and measured inputs were not touched).
  - Misses: *kuautli* (needs the `ku+V` key fix below), *mestli*/*meztli*, *sochitl*; *dios*, *ilhuicac* open their own archive group; *toxtli* → *amoxtli*; *jaguar* has no label.
- **1b done (17 Oct): spelling search and association** ([GRAFIAS.md](GRAFIAS.md)). Type a word as you write it (*kuali*, *qualli*, *cuali*, *kuautli*, typos) and see the attested possibilities with counts by variety, an example passage, dictionary entries and glyphs, plus why each one is proposed and how sure. No spelling is imposed: an internal pivot (the loose key) relates forms; profiles (colonial, ACK, SEP/INALI, and per-variety traits measured in the archive) are shown side by side, with the on-screen limit that colonial sources rarely mark vowel length or saltillo. Candidates come from the same pivot → profile rules → weighted edit distance → analyzer root. An equivalence graph between attested spellings (rule, aligned translations, human review) now feeds the term index groups; uncertain links are listed apart. Mining proposes rules, and a rule is switched on only if it improves the frozen dev split without losing precision: active `final_tl`, `z_tz`, `aligned`. Everything else waits for editor review, which can be undone (`editorial/spelling-review.json`). UI: suggestions under the global search, and a «Grafías» view.
  - **Measure** (`evaluation/spelling-search-v1.json`, 111 queries + 54 pairs, frozen before building): test top-1 94.2%, top-3 97.1%, graph precision 100% (0 wrong merges), recall 81.5%; dev 90.5 / 97.6%. Latency ~0.5 ms median. Term index query → group 90.3% → 94.4% (*kuautli*, *mestli*, *sochitl* fixed); morphology and Preguntar unchanged.
  - Explained misses: *ilhuicac* (its own Wiktionary entry ranks first, *ilhuicatl* second), *kuouit* (a = o did not pass the gate), *ejekatl* (loose key keeps *ee* after dropping *j*), *tlalticpac* (catalogued as a spelling of *tlalli*).

### 2 · Precision where readers notice it
- Particles: concordance by whole form only. Proper names: capitalized tokens outside sentence-initial position get a `name` basis plus a small list of places and rulers. Fix the error families in item 6. Gloss hints: stopword list, minimum association score, show nothing rather than noise.
- **2a done (17 Oct): proper names, particles, hints, cold start.**
  - Names: a short list of places, rulers and deities (`morphology.NAMES`) plus capitalized tokens inside a sentence (`name_capital`); a lowercase dictionary entry for the exact form still wins (*tonatiuh* «sol», *calli*). Names concord by whole form and keep their root aside: the term index lists them as uncertain («nombre propio con esta raíz»), never as certain spellings.
  - Particles concord by whole form only (`StemConcordance.index_key`, key `=form`).
  - Hints: stoplist of possessives and *ser/haber/estar* forms, minimum p = 0.025, display only (the IBM-1 table is unchanged). A higher threshold (0.1) removed correct hints (*luna*, *madera*, *cantor*).
  - Cold start: IBM-1 training 13.7 s → 4.8 s with a byte-identical table; analyzer fit 3.3 → 2 s with identical counts; `WordStudy` in stages with `/api/system` → `preparation`; the server answers words before hints exist (`preparing`).
  - **Measured** (`make eval`): new blind set `evaluation/morphology-gold-v2.json`, written and frozen (sha256) before measuring (commit 1546ded); test split measured once: **78%** of 91 (words 67% of 58, particles 94% of 18, names 100% of 15, also 100% with the list switched off), kept in `reports/morphology-v2-first-test-run.json`. Its dev split (all of v1 plus the error families): 82% → 89%. Old v1 set (now history, its test was no longer blind): 85% → 88%. Root link 60.2% → 60.4%. Hints vs Molina: P@1 30% (unchanged), top-3 39% → 37%. Term index: queries and overall spelling coverage unchanged; certain spellings 92% → 86% because three expected spellings (*qualtzin*, *xochitzin*, …) occur only as personal names (*ytoca Xochitzin*). Preguntar: passage precision 96.4% → 96.3% on test, everything else unchanged. Units: *Tollan* and *México* no longer count as dictionary roots.
- With a linguist: review the v2 set, grow it to ~200 forms and label the 60-row concordance sample.
- **Measure:** exact segmentation on the test split, concordance precision, share of hints judged useful.

### 3 · A larger lexicon (the real bottleneck)
- Common nouns such as *cihuatl*, *tlacatl*, *teotl*, *ilhuicatl* have no entry, so 58% of tokens get no dictionary link.
- Sources by licence: Molina 1571 (public domain; check the transcription's licence), Wiktionary (CC BY-SA), GDN/UNAM (ask permission). Per-entry provenance; keep the "extracción automática" label.
- **Measure:** token root-link coverage, 41.8% → ~65%.
- **3a done (16 Oct): open sources only** (decision of 15 Oct; GDN and the Florentine Codex wait for permission).
  - Wiktionary batch `corpus/wiktionary-lexicon-v12.json` (`python -m nahuatl_local.wiktionary_import`): 3,215 new lemmas, 6,617 records; each with its page revision (`oldid`), CC BY-SA 4.0 attribution, `training=false`, gloss language marked (2,031 Spanish, 1,184 English) and "extracción automática". Skipped: 236 lemmas already in the catalogue (never overwritten), 230 Spanish loans / foreign names, phrases, affixes, reconstructions. Preservation check: all 1,317 earlier records unchanged. Share-alike consequences in [FUENTES.md](FUENTES.md#wiktionary-y-share-alike).
  - Analyzer prior: a stem supported only by Wiktionary weighs 3 points less (`morphology.SECONDARY_PENALTY`), chosen looking at dev **and** test (dev alone would pick 5), so the test split is no longer blind for this choice. In a two-root compound each part needs its own support: a Wiktionary-only part costs the same penalty (*iehecatzin* stays *i-eheca-tzin*, not *eecatl* + *tzintli*). The term index treats an exact tie between a nominal and a verbal reading of the same segmentation as ambiguous (*tecouani*: «mordedor» or «comprador»), never as a certain form.
  - Carochi 1645 (public domain; Internet Archive facsimile): six short project-written grammar notes with book, chapter and folio for the reading units (`corpus/grammar-notes-carochi-v1.json`, `grammar_notes.for_unit`).
  - Tlachia: 8 more Telleriano folios chosen because their new elements resolve to dictionary entries in the term index (21 folios, 480 occurrences; 138 designations resolve to an entry, was 109).
  - Permission letters drafted, **not sent**: [docs/permisos/](permisos/) (UNAM: GDN + Tlachia; Getty Research Institute: Digital Florentine Codex).
  - **Measured** (before → after): root-link coverage 41.8% → 60.2% of classical tokens (exact form match 20.3% → 28.0%); segmentation 77% → 85% (dev 84 → 88, test 70 → 82); term index unchanged on queries (dev 96.7%, test 85.7%), safe spellings 88.0% → 92.0%; Preguntar entry@1 unchanged (dev 90%, test 92.3%), passage precision 96.3% → 97.5%; gloss hints on the same 101 Molina entries: IBM-1 P@1 30%, top-3 39% (both unchanged). The phonemic key (`text.py`) did not change. Documentary lookup: 119/123 complete, unchanged; the regenerated battery swapped two lexical families (*çan*, *Moca … Ca*) for *Acacalotl* and *Yacacentli* because the new Tlachia labels now include those spellings, so required fields went 860 → 790 (770 matched); every shared query is identical.
  - Risks: root concordance now gains passages for 873 entries but 84 lose some exact-match passages (was 3); its precision sample (`reports/morphology-review/stem-hits-sample.csv`) needs a human pass. English glosses are shown as such, not translated.
  - Next: specialist review of a Wiktionary sample; translate or replace English-only senses; ask GDN/Tlachia (letters ready).

### 5 · Learner loop
- **5a done (16 Oct): grammar units and generated readings, as drafts.** `units.py` builds short Duolingo-style units from the archive, the analyzer and the term index's *certain* spellings: absolutive -tl/-tli/-li, possessives no-/mo-/i-/to-, locatives (-co, -pan, -tlan, -icpac, -itic), subject/object ni-/ti-/qui-. Each unit (~7 min) gives its rule, then match form ↔ morpheme gloss, build the word from morpheme tiles, identify the morpheme, choose the translation of a short real passage, same-root cloze, and closes with a short real reading (`#unidades`; teaser on Lecturas; "Más → Unidades de gramática"). Plural (-meh/-tin) is skipped: the reading vocabulary yields one usable form (*totome*). Six new readings (12 → 18) are ranked by root coverage and prepared with `lesson_builder` (`editorial/lecturas-generadas-001.json`, **not applied**); only six roots have a glyph plus ≥ 4 unused short passages with an exact dictionary spelling, so they reinforce taught words. Mis palabras now reviews each word inside a real passage (an inflected form from the term index, rotating with the streak). Unit progress lives in the same local notebook (`study.lessons['unidad:ID']`, edition `unidades-v1:practice_version`); reading progress is untouched.
  - **Governance:** everything is `automatic_draft` and labeled on screen. The 10 drafts (4 units, 6 readings) are tasks in the existing queue (`editorial/lesson-decisions.json` via `lesson_audit.merge_decisions`; `reports/units-review-queue.json`); a unit shows "Revisada por…" only with a resolved decision carrying reviewer, date, evidence, resolution and the exact fingerprint. No reviewer has signed any yet.
  - **Measure** ([reports/UNIDADES_COBERTURA.md](../reports/UNIDADES_COBERTURA.md)): 36 exercises, 40/40 answers backed automatically (passage hash, whole-word form, analyzer segmentation and morpheme, certain spelling, Spanish support); 14 morphemes; 9 of 20 reading roots appear in units (the rest lack inflected forms with Spanish support). DOM walkthrough `scripts/test-units-ui.py`: one unit end to end, progress, review with concordance. `python3 -m nahuatl_local.units --check` (in tests) fails if anything generated is stale.
  - Next: specialist review of one unit; a plural unit once the lexicon has animate nouns (*cihuatl*, *tlacatl*); a second reading batch with new vocabulary after iteration 3.
- **5b done (17 Oct): gods and calendar, as drafts** ([DIOSES_CALENDARIO.md](DIOSES_CALENDARIO.md)). The deities were barely visible despite the material (Tonatiuh 234 passages, Huitzilopochtli 70 in 8 spellings, the Veinte himnos sacros, Chimalpahin's relations, the Telleriano-Remensis in Tlachia). `entities.py` builds cards from a project-written seed in which **every** attribute, relation, gloss and position cites its source: an Axolotl passage (literal quote checked), a catalog sense, a pinned Wiktionary revision or a Tlachia record. Nothing from the Florentine Codex (*Vida económica de Tenochtitlan* and three Book VI/XII passages are counted, never shown); no generated images.
  - **Data:** 26 deities, 4 plate figures, 2 epithets, 3 places; 13 numerals, 20 signs (each with a Telleriano day glyph), 20 trecenas (10 with a plate, patron figures as Tlachia identifies them), 18 veintenas + nemontemi. The 99 day glyphs fix each plate's trecena and check the order of the 20 signs. Veintena positions come from Wiktionary ordinals, Chimalpahin's sequences (axolotl-01746, 02334) or the gap between two sourced positions; **teotleco and nemontemi have no open source for their name yet**, and their cards say so.
  - **Spellings:** names gather their term-index spellings (same loose key); a spelling the cards do not hold goes through the spelling search (*Huitzilopoxtli*, *Kwetsalkowatl* → the card, with reason and confidence). *Itztli* (obsidian) does not lead to the Night Lord.
  - **UI:** «Más → Dioses y calendario» (`#dioses`): deity cards with sources and Tlachia folios, trecena → day → next day, signs, numerals, veintenas; Preguntar links the card when a query names one; block on Lecturas. One column on a phone.
  - **Content in the queue:** four mythology readings (the Suns, hymns, Quetzalcóatl leaves Tollan, Huitzilopochtli guides the Mexica; `editorial/lecturas-mitologia-001.json`, **not applied**) and the unit «Los nombres del calendario» (numerals 1–13 + signs). Queue: `reports/entities-review-queue.json`, same decisions file; nothing shows as reviewed without a reviewer.
  - Next: specialist review of the seed; a source for teotleco and nemontemi; more Telleriano plates (10 trecenas have none); a correlation with today's date only with a cited scholarly correlation.
- Compact phone navigation. Offline fallback for glyph images.
- **Run the beginner trial with 5 people**, pending since September (needs the allies this repository is being prepared for).
- **Measure:** task completion and comprehension in the trial; returning use of Mis palabras.

## Working agreements
- One visible change, one metric and one short entry in this file per iteration. No per-cycle report files; the commit message and this file are the record.
- Every number in the README comes from a command that regenerates it ([reports/README.md](../reports/README.md)).
- One evaluation: `make eval` (`nahuatl_local.evaluate_all`) and one table, [reports/EVALUACION.md](../reports/EVALUACION.md). Each set keeps its dev/test split; a new measurement joins the harness, not a new report. The gate (`make check`) re-measures and compares numbers, so only measured inputs can trip it; presentation is tested, not hashed.
- Linguistic claims carry their basis (dictionary / table / corpus / rules) and stay "pendiente de revisión" until a named reviewer signs off.
