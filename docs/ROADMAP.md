Updated 15 October 2026. This is the only planning document: `docs/PROGRESO_INTERNO.md` and the per-cycle reports were retired on this date (summary in [HISTORIA.md](HISTORIA.md); full text in git history). **Each iteration ships one change a reader can see, measured against a baseline before and after.** Linguistic review is a separate, explicit milestone, never assumed.

## Iterations

### 0 · Clone, test, demo — done 15 October 2026 (except item 4 above)
- Inputs are tracked; `reports/` keeps only current, regenerable reports plus provenance cited by distributed data ([reports/README.md](../reports/README.md)). `make reports` regenerates, `make check` validates.
- Hash gates cover only measured inputs. Presentation is verified by the DOM suite (`make test-ui`); a UI-only change no longer requires regenerating evidence.
- GitHub Actions: `make check`, Python suite, DOM suites on a clean checkout. `make test`, `make demo`.
- Pending: the "preparando análisis" state while caches build, and a target of < 10 s to the first analysis.

### 1 · One search across spellings
- Fix the analyzer key so `ku+V`, `kw` and `qu+a` map to the same symbol and `ts ≡ tz` (*kuali → kwali* but *cualli → qalli* today). Use the loose key from Preguntar in Archive and Dictionary search; show the original spelling, grouped by variety.
- **Measure:** a 50-pair spelling-variant query set (recall of the union, before/after); re-run the morphology evaluation to check nothing regresses.

### 2 · Precision where readers notice it
- Particles: concordance by whole form only. Proper names: capitalized tokens outside sentence-initial position get a `name` basis plus a small list of places and rulers. Fix the error families in item 6. Gloss hints: stopword list, minimum association score, show nothing rather than noise.
- With a linguist: grow the gold set from 52 to ~200 forms and label the 60-row concordance sample.
- **Measure:** exact segmentation on the test split, concordance precision, share of hints judged useful.

### 3 · A larger lexicon (the real bottleneck)
- Common nouns such as *cihuatl*, *tlacatl*, *teotl*, *ilhuicatl* have no entry, so 58% of tokens get no dictionary link.
- Sources by licence: Molina 1571 (public domain; check the transcription's licence), Wiktionary (CC BY-SA), GDN/UNAM (ask permission). Per-entry provenance; keep the "extracción automática" label.
- **Measure:** token root-link coverage, 41.8% → ~65%.

### 4 · Grounded explanation agent (the LLM's product role)
- Done (4a/4b, 15 Oct): `#preguntar` and `GET /api/ask` with evidence and cited explanations; the validator rejects uncited sentences, IDs outside the evidence and quoted forms not in the cited text. Extractive writer by default; Claude (`--explain-model claude`) only when its answer validates. 46/46 extractive explanations validate. Guide: [EVIDENCIA.md](EVIDENCIA.md).
- Next: a tool-using agent over `analyze_word`, `concordance`, `dictionary`, `gloss_hints`, `archive_search`; off by default; model swappable (hosted or the local LoRA). First fix documentary ranking (strip question words; dictionary form above glyph elements for "¿qué significa X?").
- **Measure:** a 40-question set scored on citation validity, faithfulness and correct abstention, against retrieval-only answers and the LoRA model.

### 5 · Learner loop
- Rank archive passages by root coverage to propose readings faster; auto-draft word help for editorial review (12 → 18 readings).
- Spaced repetition with concordance examples. Compact phone navigation. Offline fallback for glyph images.
- **Run the beginner trial with 5 people**, pending since September (needs the allies this repository is being prepared for).
- **Measure:** task completion and comprehension in the trial; returning use of Mis palabras.

### 6 · Researchers
- Concordance export as CSV and Leipzig-style IGT (later CoNLL-U), stable permalinks per passage and analysis, documented local API.
- **Measure:** one researcher completes concordance → export → citation without help.

## Working agreements
- One visible change, one metric and one short entry in this file per iteration. No per-cycle report files; the commit message and this file are the record.
- Every number in the README comes from a command that regenerates it ([reports/README.md](../reports/README.md)).
- Hash gates only for measured inputs: `documentary_retrieval_evaluation.IMPLEMENTATION` and `documentary_evaluation.FIXED`. Presentation is tested, not hashed.
- Linguistic claims carry their basis (dictionary / table / corpus / rules) and stay "pendiente de revisión" until a named reviewer signs off.
